# Project Architecture

This portfolio project contains two independent testing modules within the Motor Insurance domain.

## Module 1 – API Testing

CyberNotes Motor Insurance Demo API

↓

Postman Collection

↓

Environment Variables

↓

JavaScript Assertions

↓

Newman CLI Execution

↓

Execution Report

## Module 2 – Database Testing

Local MySQL Insurance Database

↓

Customers

↓

Vehicles

↓

Policies

↓

SQL Validation Queries

↓

Constraint & Data Integrity Validation
